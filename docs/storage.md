# 文件存储与下载

上传、封面读取和下载授权统一经过 ObjectStorage。新上传按 STORAGE_PROVIDER 选择 COS/OSS；读取、签名和删除按已有文件自身的 provider 分流。切换默认值不会自动迁移旧文件。

COS 使用 COS_BUCKET（含APPID后缀）、COS_REGION、COS_SECRET_ID、COS_SECRET_KEY。SDK 根据桶名和地域生成地址，无需另填外网访问路径。OSS 使用 .env.example 中对应配置。

桶保持私有；后端凭据需要对应对象的上传、读取和删除权限。客户端不会获得云密钥或任意读取私有对象的能力。

## 上传与保存

创建/修改先检查资料，再上传文件，最后进入 WallpaperPersistenceService 的短事务。事务内复查分类、管理员状态和必要的文件替换快照。

原文件名仅展示，UUID 生成对象键。封面先压缩，原文件只检查媒体和完整哈希，不转码；大文件流式落盘、顺序分片，不整体读入内存。

数据库事务不能回滚云上传。ProductFileCleanupService 跟踪待回收对象，删除前查商品引用，失败保留任务重试。替换旧文件在商品事务提交后清理；这是补偿机制，不是分布式事务。

## 读取与授权

封面经后端返回图片字节。公开要求已上架，管理员检查角色，已购入口按当前账号权益查询；缓存不能绕过权限。

原文件下载先检查权益，再生成短时签名地址。私有对象地址本身不等于下载权限。

LOCAL 只兼容已有本地资源读取，路径限定在配置的存储根目录，核对存在、媒体类型和大小。客户端不能指定任意服务器路径。

限制：源封面10 MiB、处理后封面4 MiB、原文件10 GiB。上传槽位仅限制单进程文件任务；多实例仍需另行设计全局限流、共享清理任务和上传方案。
